# 설치 동선 개선 — 2026-09-11

상태: 구현·소스 검증 완료. 커밋·공개 반영 이력은 루트 `CLAUDE.md`에서 관리한다.
기존 GitHub Pages와 정적 React/Babel 구조를 유지한다. 호스팅 이전은 하지 않는다.

## 변경 범위

- 한국어·영어·일본어의 첫 화면을 지출과 절약 기록의 차별점에 맞춘다.
  핵심 기능 무료·광고 포함, 은행 연동 없는 직접 입력을 첫 화면에 설명한다.
- 네 기능을 길게 나열하던 영역은 수동 선택 탭으로 정리한다.
  지출 기록이 기본 선택이며 소비 고민·절약과 목표·공유 가계부도 모두 보존한다.
  자동 전환 없이 방향키·Home·End와 클릭으로 선택한다.
- 모바일 고정 설치 영역, 빠른 기록 영역의 설치 링크를 추가한다.
  Android에서는 Google Play가 먼저, iOS/iPadOS에서는 App Store가 먼저 보인다.
  감지되지 않으면 기존 순서를 유지하며 두 스토어를 항상 제공한다.
  사용자 동작 없이 스토어로 이동시키지 않는다.
- 모바일 안전 영역과 설치 영역의 실제 높이를 반영해 마지막 정책 링크가
  가려지지 않게 한다. 높이가 낮은 가로 화면에서는 고정하지 않는다.
- 스크립트 로딩 전·차단·실패에도 정적 설명, 두 스토어 링크, 정책·문의 링크가
  남는다. 전체 기능 소개는 기존처럼 JavaScript가 필요하다.
- 번역 카피·정책 링크·앱 화면·스토어 주소·기존 공유 이미지와 이미지 메타데이터는
  유지한다. 페이지 제목·소개 문구만 새 메시지에 맞춘다.
- 앱/서버/API/DB/광고 설정은 변경하지 않는다. 미게시 기능, 가짜 리뷰·이용자 수,
  보장된 절약 효과, 실제 돈의 자동 이체·운용으로 오해할 표현을 추가하지 않는다.

## 측정 범위

기존 Google Analytics의 `store_click`과 `platform`, `location`을 보존한다.
`language`는 페이지 언어(ko/en/ja)뿐이며 회원 ID·메일·금액·입력값은 추가하지 않는다.
기기 정보는 로컬 버튼 정렬에만 사용하고 추가 전송하지 않는다.

위치는 `hero`, `quick_input`, `final_cta`, `mobile_sticky`, `nav`로 구분한다.
데스크톱의 상단 버튼은 `#download`로 이동하므로 실제 스토어 클릭으로 세지 않는다.
측정 실패는 설치 링크의 기본 동작을 막지 않는다. 정적 대체 화면의 링크에는
새 수동 클릭 이벤트를 붙이지 않는다. 광고 차단·측정 차단 시 집계 누락이 가능하다.

**클릭은 설치 완료가 아니다.** 공개 후 동일한 기간·유입 조건에서
`스토어를 클릭한 세션 / 랜딩 방문 세션`을 언어와 스토어별로 비교한다.
이벤트 수 자체는 중복 클릭을 포함하므로 방문자 수나 설치 수로 해석하지 않는다.
실제 신규 설치는 각 스토어의 집계와 별도로 확인하며, 이번 작업은 사용자별
클릭→설치 추적이나 신규 분석 도구를 추가하지 않는다. 설치 증가 효과는 아직 미측정이다.

## 수행한 검증

- `node scripts/check-landing.mjs`: 3개 언어, 고정 버전 Babel의 JSX 변환,
  실제 React 서버 렌더, 정적 대체 화면, 자산 파일·정책/내부 링크,
  한 개의 주 제목/본문 영역, 탭/패널 연결, 기기별 버튼 순서와 대체 동작,
  클릭 측정 차단·오류, 탭 클릭·키보드 처리 **219개 검사 통과**.
  실행 시 기존 페이지와 같은 고정 버전 라이브러리를 읽고 패키지를 설치하지 않는다.
- 기존 App Store·Google Play URL 모두 HTTP 200 응답 확인.
  스토어 앱 열림·설치 완료나 현재 게시 버전의 모든 기능 검증을 뜻하지 않는다.
- 로컬 HTTP 미리보기 정상 응답. 브라우저 시각 검수·실기기 QA·운영 Analytics 수신은
  이번 단계에서 수행하지 않았다. 전체 브라우저 지원이나 접근성 인증을 의미하지 않는다.

   실광고를 눌러 시험하지 않는다. 앱 설치 QA는 프로젝트의 테스트 광고 규칙을 따른다.
